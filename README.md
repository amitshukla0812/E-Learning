E-Learning Web Application

This project is a Java-based E-Learning Web Application developed using JSP, Servlets, JDBC, and MySQL. The system allows users to register, log in, browse courses, and access learning content online. It also includes an Admin Panel for managing courses and system data.

Key Features

User Registration, Login, and Logout functionality

Browse and access available courses

Course management system

Admin Panel to Add, Update, and Delete courses

Secure database connectivity using JDBC

Backend developed with Java Servlets and frontend with JSP

 Tech Stack

Java

JSP & Servlets

JDBC

MySQL

HTML, CSS, JavaScript

Bootstrap
